# 🌐 Árvore de Links — DK

Uma página pessoal para centralizar meus principais links e facilitar o acesso às minhas redes sociais e canais de contato.

🔗 **Acesse o projeto:** [Árvore de Links DK](https://arvore-de-links-dk.vercel.app/)

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar meus conhecimentos em desenvolvimento front-end, utilizando HTML5 e CSS3.

A página reúne meus principais canais de comunicação em uma interface simples, organizada e objetiva, com foco na apresentação pessoal e na facilidade de navegação.

## ✨ Funcionalidades

- 🖼️ Imagem de perfil personalizada.
- 🔗 Links para redes sociais e contato.
- 🎨 Botões estilizados com CSS.
- 🖱️ Efeitos de transição e interação ao passar o mouse.
- 📱 Estrutura preparada para evoluir e se adaptar a diferentes dispositivos.
- 🏷️ Identificação da marca DK Web Code no rodapé.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, alinhamento dos elementos e efeitos visuais.
- **Git e GitHub:** versionamento e hospedagem do código-fonte.
- **Vercel:** publicação do projeto na web.

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/dhcdouglasoc-cmyk/arvore-de-links-dk.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd arvore-de-links-dk
   ```

3. Abra o arquivo `index.html` no navegador.

Pronto! Você já pode visualizar a página localmente.
